# Glossary

Fixed terms of the documentation site, agreed before translating. Spanish and English messages follow this table, and
a term marked «kept» is written the same way in both languages, in prose as well as in code.

| Term                  | English                                                        | Spanish                           | Rule                                                                                                                                                                                                                                                                                                             |
| --------------------- | -------------------------------------------------------------- | --------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Forma UI              | Forma UI                                                       | Forma UI                          | Kept. The product name is never translated: it is written as is inside the messages, as a fixed term, and `src/brand.ts` holds it for what is not a message (the logo and the composed `aria-label`).                                                                                                            |
| Component names       | Button, IconButton, Badge, Input, Tooltip, Dialog, Tabs, Radio | the same                          | Kept. They are identifiers of the code.                                                                                                                                                                                                                                                                          |
| Prop names and values | `variant`, `size`, `loading`…                                  | the same                          | Kept, always in code font.                                                                                                                                                                                                                                                                                       |
| `token`               | token                                                          | token                             | Kept in prose too: «del token al componente». Plural: «tokens».                                                                                                                                                                                                                                                  |
| `variant`             | variant                                                        | variante                          | Kept only as the prop name. In prose it is «variante».                                                                                                                                                                                                                                                           |
| Theme                 | theme                                                          | tema                              |                                                                                                                                                                                                                                                                                                                  |
| Theme options         | Light, Dark, System                                            | Claro, Oscuro, Sistema            | «System» follows the operating system; it is never «Auto». In a sentence both languages write the option in lowercase («Theme: light», «Tema: claro»).                                                                                                                                                           |
| Language names        | English, Español                                               | the same                          | Kept: the options of the switcher name each language in itself, in every language of the page, with its own `lang` (`localeNames`). In a sentence Spanish writes the name in lowercase («Idioma: español»), and the message of each language names its own. «Language» in the label of the switcher is «Idioma». |
| Color role            | color role                                                     | rol de color                      | The job a color does (action, content, surface, navigation, status), never its look.                                                                                                                                                                                                                             |
| Type hierarchy        | type hierarchy                                                 | jerarquía tipográfica             |                                                                                                                                                                                                                                                                                                                  |
| Spacing               | spacing                                                        | espaciado                         | The `--space-*` scale.                                                                                                                                                                                                                                                                                           |
| Contrast ratio        | contrast ratio                                                 | relación de contraste             | Written «4.5:1» in English and «4,5:1» in Spanish: the number goes through `Intl`. The levels «AA» and «AAA» are kept.                                                                                                                                                                                           |
| Getting started       | Getting started                                                | Primeros pasos                    |                                                                                                                                                                                                                                                                                                                  |
| Foundations           | Foundations                                                    | Fundamentos                       |                                                                                                                                                                                                                                                                                                                  |
| Components            | Components                                                     | Componentes                       |                                                                                                                                                                                                                                                                                                                  |
| Changelog             | Changelog                                                      | Cambios                           | The design history, not package releases.                                                                                                                                                                                                                                                                        |
| GitHub                | GitHub                                                         | GitHub                            | Kept.                                                                                                                                                                                                                                                                                                            |
| Explorer              | Component explorer                                             | Explorador                        | The homepage tool that renders a component beside its JSX. In Spanish the long form is «explorador de componentes».                                                                                                                                                                                              |
| Proposed              | Proposed                                                       | Propuesto                         | A prop or an option that is in the design but not in the library yet (the Button sizes). It is listed, disabled and marked, never offered as working.                                                                                                                                                            |
| State                 | State                                                          | Estado                            | What the `state` control of the explorer offers: default, disabled, loading, with error, read-only. These are words, not code, and each is translated.                                                                                                                                                           |
| Store                 | store                                                          | store                             | Kept: it is the object that `createThemeStore` returns, and the word of the trade. Plural: «stores».                                                                                                                                                                                                             |
| Peer dependency       | peer dependency                                                | dependencia peer                  | `peer` is kept; the sentence says what it means: your application installs it once, and the package never bundles its own copy.                                                                                                                                                                                  |
| Hover                 | Hover                                                          | Hover                             | Kept: it is the term of the trade for the state of a control under the pointer, and it labels a specimen in the Button reference. The sentence under it is translated («Pasa el puntero por encima»).                                                                                                            |
| Tone                  | Tone                                                           | Tono                              | The `tone` prop of Badge. Its values (`neutral`, `blue`…) are code and stay as they are.                                                                                                                                                                                                                         |
| Tab                   | tab, tab list, panel                                           | pestaña, lista de pestañas, panel | The words around `Tabs`: a tab is the button, the panel is what it shows. `tablist`, `tab` and `tabpanel` are ARIA roles and stay in code font in both languages.                                                                                                                                                |
| Option, group, legend | option, group, legend                                          | opción, grupo, leyenda            | The words around `Radio`: an option is one radio, a group is the options that share a `name`, and the legend names the group. `fieldset` and `legend` are HTML elements and stay in code font in both languages.                                                                                                 |
| Reset                 | Reset                                                          | Restablecer                       | Puts the controls of the explorer back at their defaults.                                                                                                                                                                                                                                                        |
| Retry                 | Retry                                                          | Reintentar                        | The action after something of the site failed to load. It reloads the page (a failed chunk is not fetched again by the same document), and the sentence around it says so only as «Retrying also brings the latest version».                                                                                     |
| Dismiss               | Dismiss                                                        | Cerrar                            | Closes a notice and goes on without what failed (the search that did not load). It is «Cerrar», not «Descartar»: it hides a message, it does not discard anything.                                                                                                                                               |
| Code examples         | —                                                              | —                                 | Never translated: code, import paths and CSS stay in English; only the prose around them is translated.                                                                                                                                                                                                          |

## Catalog and search

| Term               | English                                       | Spanish                                                    | Rule                                                                                                                                                                                              |
| ------------------ | --------------------------------------------- | ---------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Search             | Search                                        | Buscar                                                     | The button and the overlay: «Search…» / «Buscar…», and the title «Search the documentation» / «Buscar en la documentación». The shortcut is printed as `⌘ K` or `Ctrl K` and is never translated. |
| Catalog categories | Actions, Forms, Navigation, Display, Feedback | Acciones, Formularios, Navegación, Visualización, Feedback | «Feedback» is kept in both languages: the design uses it. The categories are the real families of the library: «Navigation» holds Tabs, and NavItem will join it.                                 |

## Writing rules

- Messages are ICU. Variables go in as arguments (`{component}`), never by joining strings; counts use `plural`.
- The messages live in `catalogs/<name>.<language>.json`, one pair of files for the chrome and the routes (`common`),
  one for each page and one for each component reference (`catalogNames.ts` lists them). Put a message in the catalogue
  of the pages that show it: a page loads only its own, so a message in the wrong one is printed as its id.
- The two files of a pair hold exactly the same keys and the same arguments, and no id is in two catalogues.
  `npm run check:messages -w forma-ui-site` fails if they do not, or if a message is not valid ICU.
- Spanish is written for the Spanish-speaking reader in general: no regional vocabulary, and «tú» for instructions.
