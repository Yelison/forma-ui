# Design specification export

Generated by the Forma UI Builder plugin (`figma-plugin/`, v0.9) with **Export specification**, from pages 00–04 and 07 of the Forma UI Figma file. `meta.json` records the export date, the counts and the sha256 of every file. Do not edit these files by hand: export again and replace the whole directory.

- `variables.json`, `styles.json` and `components.json`: variables, text styles and component sets with their variants.
- `pages/<page>/<frame>.json`: one file per top-level frame, with layout, bound variables, explicit variable modes and resolved colors.
- `png/<page>/<frame>.png`: one image per frame.
- `svg/<page>/<component>.svg`: one SVG per icon component.

The Figma variables still hold the values that predate Resolve's token changes (#14, #65, #75). The token source follows Resolve's code (`design/resolve-c3f02f8/`), not these values, until the variables are regenerated from it (plan Task 1.4).
